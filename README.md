# Brett Bissey

Personal website featuring AI research publications, professional experience, education, and music.

Built with HTML, CSS, and JavaScript. Hosted on GitHub Pages.

## Local preview

Run `python3 -m http.server 8000` and open http://localhost:8000.

## Files

- `index.html`: content
- `styles.css`: layout and dark/light themes
- `theme.js`: theme preference control
- `.nojekyll`: serves the site directly without Jekyll
